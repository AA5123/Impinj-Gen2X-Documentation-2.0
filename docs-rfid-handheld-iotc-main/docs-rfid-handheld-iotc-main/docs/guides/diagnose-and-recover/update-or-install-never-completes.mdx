**Applies when:** [`set_os`](/api-reference/mqtt/mgmt/set-os) or [`install_certificate`](/api-reference/mqtt/mgmt/install-certificate) was sent, and no outcome ever arrives.

Work through the checks in order, and stop at the first one that fails.

1. **What did the reply say?** Code `1` means only that the reader accepted the request. Any other code means the work never started.
2. **Were you subscribed to the event topic before you sent the command?** The outcome arrives as an `alerts` event, and events are not retained; one published before your subscription was active is lost.
3. **Are the flags enabled, with a reboot since?** `firmwareUpdate` for `set_os` and `fileDownload` for `install_certificate`, set with `config_events`, which takes effect after a reboot.
4. **Are you watching for the right alert?** `set_os` reports `id: "FIRMWARE_UPDATE"`; compare `alertDetails.fwUpdateStatus.updateStatus` only against `FW update success`, and do not wait for `state: "CLEAR"`. `install_certificate` reports `id: "FILE_DOWNLOAD"` with `downloadInfo.status` `DOWNLOAD SUCCESS`, then `SAVE SUCCESS`, or `DOWNLOAD FAIL` or `SAVE FAIL`.
5. **Was it refused?** For `set_os`: `4` update in progress, `8` insufficient flash, `9` file not found, `13` update failed, `14` battery low. For `install_certificate`: `9`, `21`, `29` URL missing, `30` content missing, `34` base64 decode failed, `36` client key or certificate missing. See [FM-FW-01](/guides/diagnose-and-recover/diagnose-by-system-area#fm-fw-01) to [FM-FW-04](/guides/diagnose-and-recover/diagnose-by-system-area#fm-fw-04) and [FM-SEC-02](/guides/diagnose-and-recover/diagnose-by-system-area#fm-sec-02).
6. **Was it `reboot`?** `reboot` has no outcome event. After it is accepted, the next `CONNECTED` `mqttConnEVT` shows that a new session was established; on its own it does not show that a restart occurred.
7. **Confirm from the reader.** [`get_version`](/api-reference/mqtt/mgmt/get-version) shows the running firmware; [`get_installed_certificates`](/api-reference/mqtt/mgmt/get-installed-certificates) shows the installed certificates. The contract specifies no timeout, so decide how long to wait.

**If none apply:** collect the evidence in [Escalate to Support](/guides/diagnose-and-recover/escalate-to-support).
