Read performance depends on the physical setup first, then on the profile, then on the advanced radio settings. Work in that order, change one thing at a time, and measure each change where the reader works.

- [Choose a Performance Profile](/guides/read-tags-and-barcodes/choose-a-performance-profile) picks the named radio configuration that matches the job.
- [Configure Advanced Radio Settings](/guides/read-tags-and-barcodes/configure-advanced-radio-settings) sets power, link profile, session and the Gen2 query yourself.
- [Improve Read Performance](/guides/read-tags-and-barcodes/improve-read-performance) works through the physical setup, the regional power limit and the test method.
