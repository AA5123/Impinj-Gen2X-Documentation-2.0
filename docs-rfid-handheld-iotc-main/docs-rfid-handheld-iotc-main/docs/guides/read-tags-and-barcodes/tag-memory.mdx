A Gen2 tag has four memory banks: `RESERVED`, `EPC`, `TID` and `USER`. The operating mode's access operations read and write them, open access with a password, lock them, or kill the tag, and each tag record reports the outcome in `accessResults`.

The operations run against every tag the reader reads, and `KILL`, `PERMANENT_LOCK` and `PERMANENT_UNLOCK` cannot be undone. Read [Read and Write Tag Memory](/guides/read-tags-and-barcodes/read-and-write-tag-memory) before you configure one. The banks themselves are described in [Tag and EPC Standards](/resources/tag-and-epc-standards).
