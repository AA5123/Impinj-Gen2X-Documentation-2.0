An inventory starts and stops with [`control_operation`](/api-reference/mqtt/ctrl/control-operation), and the operating mode decides when the handheld trigger, a delay or a threshold starts or ends it. The same command starts and stops a barcode scan on a reader with an imager.

Start with [Start and Stop Inventory](/guides/read-tags-and-barcodes/start-and-stop-inventory). If operators use the trigger, continue with [Configure Trigger and Stop Conditions](/guides/read-tags-and-barcodes/configure-trigger-and-stop-conditions).
