These pages cover the application side: the code that sends commands to readers and turns their replies, events and tag data into something useful. They assume a reader that is already set up; the [Quick Start: Read Your First Tag](/guides/quick-start) gets you there.

Start with [Build a Minimal Integration in Python](/guides/build-your-integration/build-a-minimal-integration), a short tutorial that connects, starts an inventory and collects unique tags. Then:

- **Design** the integration: which pattern, which broker, and where tag data goes.
- **Exchange messages**: connect, send commands and handle replies, follow asynchronous commands, and handle events and tag data.
- **Harden for production**: retry safely, recover from disconnects, manage tag-data volume, and test.

Three facts shape everything here. Replies are paired with requests only by `requestId`. The reader executes every copy of a command it receives. Replies, events and tag data are not retained, so subscribe before you publish.
