These pages cover the messages your application exchanges with a reader, in the order you usually need them:

1. [Connect Your Application to the Broker](/guides/build-your-integration/connect-your-application): your own identity, subscriptions and QoS.
2. [Send Commands and Handle Responses](/guides/build-your-integration/send-commands-and-handle-responses): `requestId`, the success rule, and every response code.
3. [Track Asynchronous Commands](/guides/build-your-integration/track-asynchronous-commands): `set_os`, `install_certificate` and `reboot` after their code `1` reply.
4. [Handle Events](/guides/build-your-integration/handle-events): recognizing each event by its shape.
5. [Consume Tag Data](/guides/build-your-integration/consume-tag-data): parsing, deduplicating and storing `dataEVT`.
