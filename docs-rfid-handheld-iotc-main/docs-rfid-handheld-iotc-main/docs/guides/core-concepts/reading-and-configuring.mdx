These pages explain what happens on the reader itself: how the radio finds and reads tags, how those reads become `dataEVT` messages, and how the reader's configuration is split into domains with their own rules for updates, refusals and reboots.

- [How the Radio Reads Tags](/guides/core-concepts/how-the-radio-reads-tags): UHF passive RFID and EPC Gen2, from singulation to memory banks.
- [The Tag Data Stream](/guides/core-concepts/the-tag-data-stream): where tag data is published, how it is batched, and what each record carries.
- [The Configuration Model](/guides/core-concepts/the-configuration-model): configuration domains, partial updates, refusals while busy, and what a reboot changes.
