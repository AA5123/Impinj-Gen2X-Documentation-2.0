These pages explain the ideas the rest of the documentation relies on. Read them when a procedure asks you to do something and you want to know why, or before you design an integration.

- **The Communication Model** explains how the reader, the broker and your application exchange messages: MQTT as the IoT Connector uses it, endpoints and topics, the three kinds of message, what delivery guarantees you get, and how the connection is secured.
- **Reading and Configuring** explains how the radio finds tags, how reads become tag-data messages, and how the reader's configuration is organized.

Each page names the reference pages that hold the exact field definitions. The procedures are in the task sections, starting with [Manage Your Reader](/guides/manage-your-reader).
