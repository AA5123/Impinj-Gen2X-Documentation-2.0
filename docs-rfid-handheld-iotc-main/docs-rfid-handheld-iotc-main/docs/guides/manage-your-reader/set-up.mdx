Set up one reader in this order. Bootstrap gives it a network and a first MQTT endpoint; the MQTT commands on the later pages need that endpoint.

1. [Bootstrap a Reader with 123RFID Desktop](/guides/manage-your-reader/bootstrap-reader): region, Wi-Fi and the first endpoint, over USB-C.
2. [Inspect Reader Identity and Status](/guides/manage-your-reader/inspect-reader-identity-and-status): confirm the reader with `get_version`, `get_status` and `get_current_region`.
3. [Configure MQTT Endpoints](/guides/manage-your-reader/configure-mqtt-endpoints): add the control and data endpoints your integration uses.
4. [Configure Wi-Fi](/guides/manage-your-reader/configure-wi-fi): add or change the networks the reader can join.
