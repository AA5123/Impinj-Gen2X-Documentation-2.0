## 📡 [MQTT API](/api-reference/mqtt) — Handheld Sleds

The IoT Connector command and event surface of the **RFD40 and RFD90 handheld RFID reader
sleds**: every command, event and response code, generated from the IOTC contract.

This is the API the rest of this site's [guides](/guides) describe. The interface is MQTT
3.1.1, and it is the only interface the IoT Connector provides on these readers.
