A new reader has no Wi-Fi credentials or broker target. What a factory reset clears is not specified in the available sources. The table lists reader defaults and default endpoint settings. Send required fields explicitly, including `activate` and each topic entry's `qos` and `retain`.

## Reader Defaults {#documented-defaults}

| Setting | Default | Where |
|---|---|---|
| `profiles` | `BALANCED_PERFORMANCE`, when no mode is configured | Operating mode |
| The operating mode after a reboot | The reader's default operating mode | Operating mode |
| `radioStartConditions`, absent | The radio starts on `control_operation` `START` | Operating mode |
| `radioStopConditions`, absent | The inventory runs until `STOP` | Operating mode |
| `activate` | `false` | Endpoint |
| `qosCommon` | `0` | Endpoint |
| `tenantId` | Empty | Endpoint |
| `cleanSession` | `true` | Endpoint `mqttParams` |
| Publish-topic `qos` and `retain` | Both required; default endpoints use QoS `0` and retain only the Last Will topic | Endpoint `mqttParams` |
| `batching.reportingInterval` | `1000` ms; `0` also selects the minimum | Endpoint |
| `batching.maxPayloadSizePerReport` | `1024` bytes; `0` also selects the minimum | Endpoint |
| `isPreferred` | `false` | Wi-Fi profile |
| `innerAuthentication` for `ttls` and `peap` | `mschapv2` | Wi-Fi profile |
| `certSource` | `HTTP` | `install_certificate` |
| `certFormat` | PEM when omitted | `install_certificate` |

The reader's default metadata flags are documented in [Choose Tag-Data Fields](/guides/read-tags-and-barcodes/choose-tag-data-fields): `RSSI` and `SEENCOUNT` are on and the other flags are off.

## Not Documented {#not-documented}

- The reader's factory region and what a factory reset clears.
- A default for any `config_events` flag, or for the heartbeat interval.
- The reader's built-in batching behavior when an endpoint has no `batching` block.
