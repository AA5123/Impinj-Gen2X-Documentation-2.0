Short answers, each with a link to the page that covers the topic in full.

## General {#general}

#### Which Readers Does the IoT Connector Run On?

The RFD40 Premium, the RFD40 Premium Plus, the RFD40-M Premium Plus, and the RFD90 as RFD9030 or RFD9090, over Wi-Fi or a communication cradle. The RFD40 Standard runs it through a communication cradle only. The `MDM` endpoint that the guides use needs firmware `SAAFKS00-008-R00` or later.

**Details:** [What You Need](/guides/get-oriented/what-you-need)

#### Which MQTT Version Does It Use?

MQTT 3.1.1.

**Details:** [MQTT in the IoT Connector](/guides/core-concepts/mqtt-in-the-iot-connector)

#### Is There a REST API?

No. The IoT Connector interface on these readers is MQTT 3.1.1, and the contract defines no HTTP surface.

**Details:** [What the IoT Connector Is](/guides/get-oriented/what-the-iot-connector-is)

#### Which Broker Do I Use, and Where Do Credentials Come From?

You provide the broker, and any MQTT 3.1.1 broker that accepts the reader's topics works. Credentials come from your broker's administration: the reader sends a username and password in the MQTT CONNECT packet, or presents a client certificate over TLS.

**Details:** [What You Need](/guides/get-oriented/what-you-need#broker)

#### Is the MQTT API Versioned?

Replies carry an `apiVersion`, and the contract records several values, such as `V1.0`, `V1.1` and `V1.21`. A complete firmware-to-API-version mapping is not specified in the available sources; the firmware history records API `1.21` in `SAAFKS00-013-R02`.

**Details:** [Changelog](/api-reference/mqtt/changelog)

#### Can One Reader Send to More than One Destination?

Yes. A reader can have several endpoints, each with its own broker, credentials, TLS settings and topics, but only `DATA1` can stream tag data: `DATA2` is currently not supported.

**Details:** [Endpoints, Topics, and Channels](/guides/core-concepts/endpoints-topics-and-channels)

## Connectivity and MQTT {#connectivity-and-mqtt}

#### Which Ports Does the Reader Use?

The port you configure on each endpoint: conventionally `8883` for MQTT over TLS and `1883` for plain MQTT.

**Details:** [TLS and Authentication](/api-reference/mqtt/protocol-reference/tls-and-authentication)

#### Is TLS Required?

No, but plain MQTT sends everything, including credentials, unencrypted. Use TLS on any network you do not trust, with `VERIFY_HOST_AND_PEER` in production.

**Details:** [Secure an Endpoint with TLS and Client Certificates](/guides/manage-your-reader/secure-an-endpoint)

#### How Do I Know the Reader Reconnected?

A `CONNECTED` `mqttConnEVT` shows that a new session was established, and `heartBeatEVT` resumes at its interval. The absence of a `DISCONNECTED` message does not mean the reader is connected.

**Details:** [Monitor Reader Connectivity](/guides/operate-and-monitor/monitor-reader-connectivity)

#### How Many Wi-Fi Profiles Can the Reader Store?

The contract does not state the maximum. A `set_wifi` beyond it returns code `19`.

**Details:** [Configure Wi-Fi](/guides/manage-your-reader/configure-wi-fi)

#### Does the Reader Keep Data While It Is Offline?

The contract describes no store-and-forward, so plan as if anything published during an outage is lost.

**Details:** [Recover from Disconnects](/guides/build-your-integration/recover-from-disconnects)

## Reading and RF Performance {#reading-and-rf-performance}

#### Which Operating-Mode Profiles Are There?

`BALANCED_PERFORMANCE`, the default, `CYCLE_COUNT`, `DENSE_READERS`, `OPTIMAL_BATTERY` and `ADVANCED`. `FAST_READ` is also listed, but its status is not settled.

**Details:** [Choose a Performance Profile](/guides/read-tags-and-barcodes/choose-a-performance-profile)

#### Which Tags Can the Reader Read?

EPC Gen2 UHF tags, standardized as ISO/IEC 18000-63.

**Details:** [Tag and EPC Standards](/resources/tag-and-epc-standards)

#### Can I Read the TID?

Yes. Enable the `TID` flag in `tagMetaDataToEnable`, or add a `READ` access operation on the TID bank.

**Details:** [Choose Which Tag Fields Are Reported](/guides/read-tags-and-barcodes/choose-tag-data-fields)

#### How Do I Filter Tags?

A `select` pre-filter decides which tags take part in the inventory; a post filter decides which read tags each data endpoint reports.

**Details:** [Pre-Filter Tags with Select](/guides/read-tags-and-barcodes/pre-filter-tags-with-select) · [Post-Filter Reported Tags](/guides/read-tags-and-barcodes/post-filter-reported-tags)

#### Does the Operating Mode Survive a Restart?

No. The reader returns to its default operating mode on reboot; re-apply yours. Whether other settings survive is not specified in the available sources.

**Details:** [The Configuration Model](/guides/core-concepts/the-configuration-model#reboots)

## Configuration and Firmware {#configuration-and-firmware}

#### What Certificate Format Does the Reader Need?

PEM, with PKCS1 private keys, at most 4 KB of content. A client certificate must be installed with its key.

**Details:** [Install and Manage Certificates](/guides/manage-your-reader/install-and-manage-certificates)

#### How Do I Update Firmware?

Send `set_os` with the image's URL; the reply is code `1`, and the outcome arrives in `FIRMWARE_UPDATE` alerts. Confirm with `get_version`. Whether an older image can be installed is not specified in the available sources.

**Details:** [Update Firmware and Restart the Reader](/guides/manage-your-reader/update-firmware-and-restart)

## Fleet and Deployment {#fleet-and-deployment}

#### How Do I Update Firmware Across a Fleet?

Send `set_os` to a few readers first, confirm them, then continue in stages.

**Details:** [Roll Out Changes in Stages](/guides/scale-to-a-fleet/roll-out-changes-in-stages)

#### How Do I Detect Configuration Drift?

Read each configuration domain from each reader, compare it with your baseline, and correct the differences domain by domain.

**Details:** [Keep Configuration Consistent](/guides/scale-to-a-fleet/keep-configuration-consistent)

#### How Do I Watch Fleet Health?

Subscribe to `heartBeatEVT` and `mqttConnEVT` from every reader with a `+` wildcard in the serial-number position, and show each reader's latest evidence and its age.

**Details:** [Build a Fleet Health View](/guides/operate-and-monitor/build-a-fleet-health-view)
