The reader reads EPC Gen2 UHF tags, standardized as ISO/IEC 18000-63. For how the radio finds tags — singulation, sessions, the Q parameter and Select — see [How the Radio Reads Tags](/guides/core-concepts/how-the-radio-reads-tags).

### Memory Banks

| Bank | Index | Purpose | Read | Write |
|---|---:|---|---|---|
| RESERVED | 0 | Access and kill passwords | Yes (password-protected) | Yes (password-protected) |
| EPC | 1 | The CRC, the Protocol Control word and the EPC | Yes | **Yes** |
| TID | 2 | Factory-programmed tag identification | Yes | Typically read-only |
| USER | 3 | Application-writable data | Yes | **Yes** |

### Tag Access Operations Supported

Via `set_operating_mode` at `operatingMode.operatingModes.accessOperations`:

| Operation | Action |
|---|---|
| `READ` | Read words from a memory bank |
| `WRITE` | Write hex data to a memory bank |
| `ACCESS` | Authenticate to the tag using access password |
| `LOCK` | Apply a `lockAction` — `UNLOCK`, `READ_AND_WRITE`, `PERMANENT_LOCK` or `PERMANENT_UNLOCK` — to `EPC`, `ACCESS_PWD`, `KILL_PWD`, `TID`, `USER` or `ALL` |
| `KILL` | Permanently and irreversibly disable the tag |

Constraints:

- `password` is 8 hex characters (32 bits) for ACCESS, LOCK, KILL.
- `offset` and `length` count 16-bit words; a `select` pre-filter counts bits.
- `data` for WRITE is hex in whole 16-bit words.
- `LOCK` with `lockAction: PERMANENT_LOCK` or `PERMANENT_UNLOCK` is irreversible.
- `KILL` is irreversible, the tag never responds again.

Each tag record reports the outcome of every configured operation in `accessResults`. See [Read and Write Tag Memory](/guides/read-tags-and-barcodes/read-and-write-tag-memory).
