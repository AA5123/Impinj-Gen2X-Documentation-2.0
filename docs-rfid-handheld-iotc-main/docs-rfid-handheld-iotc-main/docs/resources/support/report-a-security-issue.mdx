Report a suspected vulnerability privately. Do not open a public issue, pull request or discussion, and do not post it in a community forum: public disclosure before a fix puts users at risk.

## Choose the Right Channel {#channel}

| The vulnerability is in | Report it to |
|---|---|
| The reader, its firmware, the IoT Connector or the MQTT API | Zebra Product Security, through Zebra's official channels at [zebra.com](https://www.zebra.com/) |
| This documentation site, its build or its hosting | The contact in the security policy of the documentation repository |

If you are unsure which applies, use the documentation repository's security contact; reports that belong elsewhere are routed on.

## What to Include {#include}

- What is affected, and on which firmware or page.
- How to reproduce it, step by step.
- What an attacker could do with it.
- How you found it, and whether you have told anyone else.

Do not include live credentials, private keys or other people's data. Describe them instead.
