How to get help with a reader, the MQTT API or this documentation:

1. **Help yourself first.** [Get Help](/resources/support/get-help) lists the fastest routes, starting with [Diagnose and Recover](/guides/diagnose-and-recover).
2. **Check what is known.** [Known Issues and Open Questions](/resources/known-issues-and-open-questions) records deviations and behaviors not yet specified.
3. **Collect the evidence** before you contact anyone: see [Escalate to Support](/guides/diagnose-and-recover/escalate-to-support).
4. **Report it** through the right channel: a bug or feature request, or, privately, a security issue.
