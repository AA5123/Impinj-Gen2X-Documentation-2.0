## How the MQTT API Is Versioned {#versioning}

The MQTT API is defined by one contract, whose version is the IoT Connector API version it describes, currently 1.22.0. Its earlier revisions only added or relaxed, but version 1.22.0, regenerated from the IoT Connector API definition, also narrows what the contract accepts. How deprecated fields and values are marked, and what the contract does not yet specify about removal, is in [Versioning and Compatibility](/api-reference/mqtt/versioning-and-deprecation-policy). What each version changed is in the [Changelog](/api-reference/mqtt/changelog).
