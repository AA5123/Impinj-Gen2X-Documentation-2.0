> 📕 **REFERENCE** · **Audience:** API consumer · **Use:** find the page you need in this reference

This is the REST API reference for the Zebra FXR60 and FXR90 fixed RFID readers running
IoT Connector. Its [operation reference](/api-reference/rest/endpoints) is rendered directly
from the vendor's OpenAPI 3.1 document, so every path, parameter, schema and response in it
is the specification itself. It covers the fixed reader line only — the RFD40 and RFD90
handheld sleds use MQTT and are documented in the [MQTT API](/api-reference/mqtt) reference.
