The [MDM](/api-reference/mqtt/protocol-reference/connection-and-session#endpoint-types) endpoint lets a management platform manage the reader over its own MQTT broker. Configure it with [`config_endpoint`](/api-reference/mqtt/mgmt/config-endpoint) by selecting `epType: MDM`. It uses the same [topic slots](/api-reference/mqtt/protocol-reference/endpoints-and-topic-slots) as [`MGMT`](/api-reference/mqtt/protocol-reference/connection-and-session#endpoint-types). See [What Changes When You Scale](/guides/scale-to-a-fleet/what-changes-when-you-scale).

### `epType: MDM` (Generic MDM)

A standardized, lightweight set of IOTC management APIs that any MDM platform can implement. 123RFID Desktop creates this endpoint first and enrolls the sled; every other endpoint is then added remotely through it. Most parameters remain user-configurable through the 123RFID applications. 42Gears (SureMDM) is a current implementation of the Generic MDM API set.
