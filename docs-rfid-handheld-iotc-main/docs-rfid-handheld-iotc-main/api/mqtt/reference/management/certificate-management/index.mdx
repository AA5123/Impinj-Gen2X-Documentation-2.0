These commands install, list and delete the certificates a reader uses for TLS, 802.1X Wi-Fi and downloads. [`install_certificate`](/api-reference/mqtt/mgmt/install-certificate) replies with [code `1`](/api-reference/mqtt/response-codes#code-1) and reports its outcome later in an [`alerts`](/api-reference/mqtt/events/alerts-event) event with `id: "FILE_DOWNLOAD"`. [`get_installed_certificates`](/api-reference/mqtt/mgmt/get-installed-certificates) is safe to send again and reports each certificate's validity dates. [`delete_certificate`](/api-reference/mqtt/mgmt/delete-certificate) without a `name` deletes every certificate of the given type.

See [Install and Manage Certificates](/guides/manage-your-reader/install-and-manage-certificates) and the [Certificates](/api-reference/mqtt/schemas/certificates) schemas.
