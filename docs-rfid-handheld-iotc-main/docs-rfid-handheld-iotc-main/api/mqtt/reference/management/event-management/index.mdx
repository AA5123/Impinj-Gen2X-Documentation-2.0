[`config_events`](/api-reference/mqtt/mgmt/config-events) chooses which events the reader publishes: the heartbeat and its interval, and the alert conditions. A change takes effect only after the reader reboots. There is no read command of its own; the settings show in the `eventConfiguration` block of the [`get_endpoint_config`](/api-reference/mqtt/mgmt/get-endpoint-config) read-back. On v1.1, only the `heartbeat`, `battery`, `power`, `network`, `firmwareUpdate`, `fileDownload` and `terminalConnection` flags have an effect; the rest are reserved.

See [Configure Event Reporting](/guides/operate-and-monitor/configure-event-reporting) and the [Event Reporting](/api-reference/mqtt/schemas/event-reporting) schemas.
