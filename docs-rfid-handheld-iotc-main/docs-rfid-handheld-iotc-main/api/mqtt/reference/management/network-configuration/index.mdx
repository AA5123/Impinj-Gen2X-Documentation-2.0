These commands manage the reader's Wi-Fi profiles and read its Ethernet interface. [`set_wifi`](/api-reference/mqtt/mgmt/set-wifi) creates or modifies one profile per request; [`delete_wifi_profile`](/api-reference/mqtt/mgmt/delete-wifi-profile) removes one, but not the one the reader is connected to ([code `16`](/api-reference/mqtt/response-codes#code-16)). [`get_wifi`](/api-reference/mqtt/mgmt/get-wifi) and [`get_eth`](/api-reference/mqtt/mgmt/get-eth) are safe to send again. The MQTT API has no command that changes Ethernet settings.

The first Wi-Fi profile is set with 123RFID Desktop, because the reader needs a network before it can receive an MQTT command. See [Configure Wi-Fi](/guides/manage-your-reader/configure-wi-fi) and the [Network](/api-reference/mqtt/schemas/network) schemas.
