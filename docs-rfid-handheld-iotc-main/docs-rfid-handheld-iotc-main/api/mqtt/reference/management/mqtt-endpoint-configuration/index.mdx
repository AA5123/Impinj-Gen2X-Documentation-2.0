An endpoint is a named MQTT connection configuration stored on the reader: its broker, security and topics. [`config_endpoint`](/api-reference/mqtt/mgmt/config-endpoint) adds, updates, activates and deletes endpoints; [`get_endpoint_config`](/api-reference/mqtt/mgmt/get-endpoint-config) reads them back and is safe to send again.

- The position of each publish topic decides what the reader publishes on it; see [Endpoints and Topic Slots](/api-reference/mqtt/protocol-reference/endpoints-and-topic-slots).
- The reader refuses to change an active endpoint ([code `35`](/api-reference/mqtt/response-codes#code-35)), and refuses an `add` for a name that exists ([code `10`](/api-reference/mqtt/response-codes#code-10) or `33`).

See [Configure MQTT Endpoints](/guides/manage-your-reader/configure-mqtt-endpoints) and the [MQTT Endpoints](/api-reference/mqtt/schemas/mqtt-endpoints) schemas.
