Three read commands report what a reader is and what state it is in. Each is safe to send again, and each can return [code `3`](/api-reference/mqtt/response-codes#code-3) when the reader cannot gather the information at that moment.

| Command | Reports |
| --- | --- |
| [`get_version`](/api-reference/mqtt/mgmt/get-version) | Model, serial number, SKU and firmware versions |
| [`get_status`](/api-reference/mqtt/mgmt/get-status) | Power source, battery, radio activity and connection, system time |
| [`get_current_region`](/api-reference/mqtt/mgmt/get-current-region) | The [regulatory region](/api-reference/mqtt/mgmt/get-current-region): country, standard, channels, and power limits |

No MQTT command changes the region. See [Inspect Reader Identity and Status](/guides/manage-your-reader/inspect-reader-identity-and-status).
