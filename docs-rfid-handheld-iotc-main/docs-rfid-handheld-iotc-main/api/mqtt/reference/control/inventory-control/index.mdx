[`control_operation`](/api-reference/mqtt/ctrl/control-operation) starts and stops an RFID inventory, with `controlType: "RFID"`, or a barcode scan, with `controlType: "SCANNER"`. A `START` during an inventory returns [code `11`](/api-reference/mqtt/response-codes#code-11); a `STOP` while the radio is idle returns [code `12`](/api-reference/mqtt/response-codes#code-12), which is not a failure. When the [operating mode](/api-reference/mqtt/ctrl/set-operating-mode) sets start or stop conditions, the trigger and thresholds also start and stop an inventory.

See [Start and Stop Inventory](/guides/read-tags-and-barcodes/start-and-stop-inventory).
