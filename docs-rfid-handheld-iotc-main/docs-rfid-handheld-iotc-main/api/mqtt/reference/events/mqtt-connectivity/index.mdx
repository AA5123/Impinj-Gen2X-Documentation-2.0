[`mqttConnEVT`](/api-reference/mqtt/events/mqtt-connection-event) reports the state of a reader's MQTT session. The reader publishes `CONNECTED` when a session is established. If the session ends without a clean disconnect, the broker publishes the reader's [Last Will](/api-reference/mqtt/protocol-reference/qos-and-delivery-semantics#retention-and-last-will): the `DISCONNECTED` form, without a timestamp. A clean disconnect suppresses the Will, and the contract does not say whether the reader reports one, so the absence of a `DISCONNECTED` message does not mean the reader is connected.

See [Monitor Reader Connectivity](/guides/operate-and-monitor/monitor-reader-connectivity).
