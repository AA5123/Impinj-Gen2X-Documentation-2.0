[`dataEVT`](/api-reference/mqtt/data/tag-data-event) carries tag and barcode reads in batches. Each tag record reports one tag since its previous report, with `eventNum` as its only required member; the [operating mode](/api-reference/mqtt/ctrl/set-operating-mode)'s metadata flags decide which other fields it carries. Barcode records carry `decodedBarcode` and `symbology`.

See [Consume Tag Data](/guides/build-your-integration/consume-tag-data) and the [RFID and Barcode Reading](/api-reference/mqtt/schemas/rfid-and-barcode-reading#tag-data) schemas.
