> 📕 **REFERENCE** · **Audience:** API consumer · **Use:** read the reader's wired Ethernet interface configuration and status

## Overview

`get_eth` retrieves the reader's **wired Ethernet interface configuration and status** — interface state, live link status and speed, and the DHCP-assigned IPv4 addressing. It is a read-only query on the device-management ([MGMT](/api-reference/mqtt/protocol-reference/connection-and-session#endpoint-types)) endpoint, useful for verifying that the reader's wired uplink is up and reaching back-end services.

The response shape depends on interface state: when Ethernet is **enabled** the device returns the full `interfaceDetails` (hostname, MAC, link, IPv4); when it is **disabled** it returns only `interfaceName` and `status` (still a [`code 0`](/api-reference/mqtt/response-codes#code-0) success). Note that, per the command's own contract, **static IP configuration and IPv6 are not available in the current API version**, and the 802.1X `security` block is not populated (see [Response Semantics](#response-semantics) below).

## When to Use

Use `get_eth` when you need to **verify the reader's wired network state** — during commissioning, provisioning verification, or troubleshooting a wired uplink. Because it is read-only and idempotent, it is safe to poll.

- **Confirm connectivity:** check `interfaceDetails.status` (enabled?), `linkStatus.status` (cable connected?), and `linkStatus.linkSpeed` (negotiated speed).
- **Validate addressing:** check `ipv4Configuration.ipAddress`, `gateway`, and `enableDhcp` to confirm the reader has a working IPv4 route to the broker / back-end.
- **Troubleshoot wired issues:** an unexpected `linkSpeed`, a missing IP, or a `Disabled` interface each point to a specific cable/switch/config problem.

## Key Fields

- **`requestId`** (request) — your correlation token; make it unique per request. The device echoes it in the response so you can pair reply to request.
- **`ethConfig.interfaceDetails.status`** (response) — `Enabled` or `Disabled`. When `Disabled`, only `interfaceName` and `status` are returned.
- **`ethConfig.interfaceDetails.linkStatus`** (response) — `status` (`Connected` / `Disconnected`) and `linkSpeed`; the live carrier state.
- **`ethConfig.interfaceDetails.ipv4Configuration`** (response) — the DHCP-assigned IPv4 addressing (reported read-only).
- **`response.code`** (response) — read this to determine success vs failure (see [Response Codes](#response-codes)).

## Response Semantics

- **Not available in the current API version.** Per this command's contract, **static IP configuration and IPv6 are not available in the current API version.** The response schema models a `security` / `EAP802_1X` block and a full `ipv4Configuration`, but:

  - the `security` block is **reserved** (planned for a future release) and is **not populated**;
  - `ipv4Configuration` is **reported read-only** — the reader's addressing is DHCP-assigned, and you **cannot set a static IP** through this API;
  - **no IPv6** addressing is returned.
- **Disabled interface.** When Ethernet is disabled, the response contains only `ethConfig.interfaceDetails.interfaceName` and `status` (`Disabled`) — `linkStatus`, `ipv4Configuration`, `hostname`, and `macAddress` are absent. This is normal behavior and a [`code 0`](/api-reference/mqtt/response-codes#code-0) success, not an error.

## Response Codes

`get_eth` returns `response.code`. The codes applicable to this command are below; for the full table see the [Response Codes](/api-reference/mqtt/response-codes) and [Correlation and Request/Response Pairing](/api-reference/mqtt/protocol-reference/message-envelope#correlation-and-request-response-pairing).

| Code | Description |
| --- | --- |
| `0` | Success — Ethernet configuration retrieved and returned. A **disabled** interface is also a `0` success (minimal payload), not an error. |
| `3` | Not able to retrieve information (`IOT_ERROR_INFO_NOT_AVAILABLE`) — the device could not gather the interface details at this time. Retry after a short delay; if it persists, reboot the device. |
| `101` | Default error — generic catch-all. |
